# setnote-daily

세트노트(iPhone 앱) 운동 탭의 **오늘의 추천 운동** 파일입니다.

- `recommend.json`: 날짜마다 하체·팔·등·가슴의 추천 종목 4개(첫 추천 1 + 예비 3)와 세트마다 무게·횟수·휴식.
- 매일 새벽 자동으로 어제부터 9일치를 새로 만들어 올립니다. 손으로 고치지 않습니다.
- 앱은 이 파일 하나만 받아 오며, 받을 때 기기 정보나 운동 기록을 보내지 않습니다. 받지 못하면 앱이 같은 규칙으로 직접 고릅니다.
- 무게·횟수는 운동 2~3년 차 남성 기준의 일반적인 값입니다. 자신의 몸 상태에 맞게 줄이거나 바꿔 쓰세요.

형식(v 1):

```
{ "v": 1, "days": { "YYYY-MM-DD": { "legs" | "arms" | "back" | "chest": [ { "ex": 종목 id, "plan": [ { "warm"?: true, "w"?: kg, "r": 횟수, "rest": 초 } ], "after": 초 } ] } } }
```
